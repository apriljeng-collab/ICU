# 開心打小人

一個可愛風嘅「打小人」手機網頁遊戲，送俾受咗氣嘅朋友出口氣、調整心情。

- **打小人**：寫低小人名（花名都得），揀類型，用拖鞋／紙扇等兵器打佢。打得越多，小人會起包、暈、喊、包紮。
- **收功三部曲**：祭白虎（餵豬肉）→ 化小人（燒成星星）→ 擲聖杯，完成後有一句打氣說話，功德 +10。
- **敲木魚**：敲一下功德 +1，可以開自動敲；功德用嚟解鎖膠錘仔、雞毛掃、大枕頭、鹹魚。
- **心情簿**：累積紀錄、兵器庫、一分鐘深呼吸，同埋情緒支援熱線。

全部係一個 `index.html`，冇外部依賴（字體由 Google Fonts 載入），紀錄存喺手機瀏覽器本機。
用手機 Safari 打開後揀「加至主畫面」，就可以好似 App 咁用。
