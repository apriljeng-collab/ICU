# 開心打小人

一款可愛風的「打小人」手機網頁遊戲，送給受了委屈的朋友出口氣、調適心情。

- **打小人**：寫下小人名字（綽號也可以），選類型，用藍白拖、紙扇等兵器打他（共 9 種兵器，各有音效）。打越多下，小人會腫包、頭暈、哭哭、包紮。
- **收功三部曲**：祭白虎（餵豬肉）→ 化小人（燒成星星）→ 擲聖杯，完成後有一句打氣的話，功德 +10。
- **敲木魚**：敲一下功德 +1，可開自動敲；功德可解鎖吱吱槌、愛的小手、雞毛撢子、拳擊手套、大枕頭、鹹魚、棒球棒。
- **背景音樂與音效**：打小人時是輕快的木琴小調，敲木魚、收功時換成安靜的拇指琴；每個動作都有對應音效（換兵器、連擊、小人求饒、白虎呼嚕、燒紙、擲筊的聖杯／笑杯／陰杯等）。音樂和音效可分開開關，全部由程式即時合成，不需要音檔。
- **心情簿**：累積紀錄、兵器庫、一分鐘深呼吸，以及心理支持專線（1925、1995、1980）。

整個遊戲只有一個 `index.html`，沒有其他依賴（字型由 Google Fonts 載入），紀錄只存在手機瀏覽器本機。
用 iPhone Safari 開啟後選「加入主畫面」，就能像 App 一樣使用。
